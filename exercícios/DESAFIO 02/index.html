TAGS EM HTML

Em HTML a gente pode escrever coisas no nosso site utilizando algumas tags, que são responsáveis por organizar e ordenar cada coisa que iremos escrever
essas são algumas tags que utilizamos:

  • Parágrafo
  • Títulos
  • Imagens
  • Abreviações
  • Citações
  • Códigos fonte
  • Listas
  • Itálico
  • Negrito
